# Flowday

Пространство для важных задач без визуального шума. Тестовое приложение на **React, TypeScript и Effector**, с компонентами **Mantine** и иконками **Lucide**.

## Запуск

Нужен Node.js 22.12+ и npm. В Windows PowerShell при ограниченной политике выполнения используйте `npm.cmd` вместо `npm`.

```sh
npm ci
npm run dev
```

Адрес разработки — `http://localhost:5173`.

```sh
npm run build
npm run preview
```

Production-просмотр — `http://localhost:4173`. PWA и офлайн-режим проверяются на production-сборке.

## Возможности

- Задачи с описаниями, подзадачами, тегами, сроками и четырьмя уровнями приоритета.
- Статусы «К выполнению», «В работе», «Готово», дублирование и удаление с отменой.
- Проекты с цветами, редактированием и удалением с сохранением задач.
- Разделы «Сегодня», «Предстоящее», «Все задачи», «Входящие» и «Выполненное».
- Просроченные задачи в плане на сегодня, выбор даты в предстоящих задачах.
- Список и канбан с перетаскиванием; на сенсорных устройствах статус меняется через меню или редактор.
- Поиск в текущем разделе по названию, описанию, тегам и подзадачам; фильтр приоритетов и четыре способа сортировки.
- Быстрый ввод, сворачиваемые группы и компактный режим.
- Фокус-таймер с привязкой к задаче, паузой, продолжением, отдыхом, настройкой длительности и дневной целью.
- Учёт времени по задачам, статистика за день и неделю, прогресс проектов.
- Светлая, тёмная и системная темы; локальные Manrope, Inter и Lora с кириллицей.
- Адаптивный интерфейс от 320 px, мобильное меню и поддержка reduced motion.
- PWA с обычными и maskable-иконками, офлайн-кэшем и предложением обновления.
- Кнопка установки в настройках и инструкция для Safari и браузеров без системного диалога установки.
- Сохранение на устройстве, проверяемые резервные копии JSON, экспорт, импорт и подтверждение очистки.

При первом запуске доступны примеры задач. Начать с чистого списка можно в настройках.

## Данные и таймер

Данные хранятся в `localStorage` этого браузера под ключом `flowday:v1`. Сервер, аккаунт и синхронизация между устройствами не требуются. Для переноса используйте экспорт и импорт. Очистка данных браузера удаляет локальное пространство.

Таймер опирается на временные метки, а не на число вызовов `setInterval`: переключение вкладки и перезагрузка не сбивают отсчёт. При паузе, сбросе и переключении задачи время записывается один раз. Отдых не попадает в статистику фокуса. Экспорт фиксирует актуальное состояние таймера на паузе.

При закрытом приложении браузер не воспроизводит звук. После открытия приложение восстанавливает отсчёт и обрабатывает завершение. Звуковой сигнал работает после взаимодействия с таймером, согласно ограничениям браузера.

Импорт проверяется Zod: формат, версия, даты, пределы значений, объём файла и повторяющиеся идентификаторы. Данные заменяются после подтверждения. При повреждённом локальном сохранении приложение показывает предупреждение и по возможности оставляет исходный JSON в `flowday:recovery`.

## Архитектура

```text
src/
  components/       Интерфейс задач, проектов, фокуса, статистики и настроек
  model/
    schema.ts       Схемы Zod и типы данных
    index.ts        События и хранилища Effector, сохранение и переходы состояния
    logic.ts        Чистые функции выборки задач и учёта времени
    seed.ts         Демонстрационные данные с актуальными датами
    logic.test.ts   Тесты фильтров, таймера и резервных копий
  App.tsx           Компоновка, навигация и окна приложения
  pwa.ts            Установка, обновление и сетевой статус
  sound.ts          Мягкий сигнал через Web Audio
  fonts.css         Локальные WOFF2 для латиницы и кириллицы
  styles.css        Токены оформления и адаптивная вёрстка
tests/
  app.spec.ts       Браузерные сценарии Playwright и axe
```

Доменные данные и состояние таймера находятся в Effector. Локальное состояние форм и окон — в React. Даты в модели хранятся как локальные календарные даты, время — как числовые метки. Сборка разделяет React, UI-библиотеку, модель и код приложения на отдельные чанки.

## Проверки

```sh
npm run typecheck
npm run lint
npm run format:check
npm test
npm run test:e2e
```

На Windows браузерные тесты по умолчанию используют установленный Chrome. На Linux и в CI сначала выполните:

```sh
npx playwright install --with-deps chromium
```

Браузер можно выбрать через `PLAYWRIGHT_CHANNEL`. Тесты запускают production-сборку самостоятельно, используют отдельные контексты и не затрагивают ваши задачи. Проверяются CRUD, подзадачи, восстановление удаления, поиск, перетаскивание, таймер с ускоренным временем, темы и шрифты, ширины 320–1920 px, резервные копии, доступность WCAG AA и работа PWA без сети. Снимки экрана создаются в `artifacts/`, отчёты об ошибках — в `test-results/`.

Версии зависимостей закреплены, `package-lock.json` включён. `overrides` закрепляют совместимые проверенные версии `glob` и `minimatch` с исправлениями, а `deepmerge` — на версии до появления зарегистрированной уязвимости. Проверка `npm audit` после установки: **0 уязвимостей**.

## Горячие клавиши

| Клавиша                | Действие                        |
| ---------------------- | ------------------------------- |
| `N`                    | Создать задачу                  |
| `/` или `Ctrl/Cmd + K` | Перейти к поиску                |
| `?`                    | Показать подсказку              |
| `Esc`                  | Закрыть окно или мобильное меню |

## Размещение

Содержимое `dist/` можно разместить на статическом хостинге в корне домена. Для установки PWA нужен HTTPS; `localhost` поддерживается для разработки. Все шрифты и ресурсы поставляются вместе с приложением. После первого успешного открытия service worker сохраняет приложение для автономной работы.
